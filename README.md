# Spatial Expense Management System

A modern Personal Expense Management System built using an
Infinite Financial Canvas / Spatial UI.

## Features

- User authentication
- Admin authentication
- Income and expense management
- Transaction categorization
- Monthly budgets
- Category-wise spending
- Budget vs actual comparison
- Monthly spending trends
- Historical financial analysis
- Admin user management
- Admin category management
- Infinite spatial canvas
- 3D financial health visualization
- Interactive charts
- Responsive design

## Tech Stack

Frontend:
- React
- TypeScript
- Vite
- Tailwind CSS
- Three.js
- Lucide React

Backend:
- Node.js
- Express.js
- JWT
- bcryptjs

Database:
- SQLite

## Project Structure

src/       → Frontend
server/    → Backend
public/    → Static assets
